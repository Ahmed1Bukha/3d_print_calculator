# Farm D Plus - 3D Printing for Modern Farms

A beautiful and elegant Next.js website showcasing 3D printing services for agricultural applications.

## Features

- 🎨 Beautiful and modern UI with gradient designs
- 📱 Fully responsive on all devices
- 🌐 Arabic language support (RTL)
- ⚡ Built with Next.js 16 and TypeScript
- 🎭 Smooth animations and transitions
- 🎯 Optimized for performance

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Tech Stack

- **Framework:** Next.js 16
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Icons:** Lucide React
- **Font:** Cairo (Arabic + Latin)

## Sections

- Hero Section with call-to-actions
- Products Showcase
- Services Overview
- About Us
- Contact Form
- Footer with Newsletter

## Building for Production

```bash
npm run build
npm start
```
